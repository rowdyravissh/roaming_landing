# Roaming — Landing Page

This repository contains the standalone, mobile-first, and responsive landing page for the **Roaming** global travel eSIM service.

## Tech Stack
- Standalone HTML5 with responsive Tailwind CSS
- Zero build tools or Node.js runtime required (runs immediately in any browser or static host)
- Optimized for mobile screens, tablets, and desktop laptops

## Features
- Interactive instant country destination search filter
- Live destination pricing cards (Japan, Europe Regional, USA, UK, Thailand, Switzerland)
- Plan selection interactive modal
- How it works 3-step walkthrough
- Device compatibility quick-check (*#06# EID dialer check)
- Responsive FAQ accordion
- Mandatory regulatory and telecommunication disclaimers

## Deployment
Can be deployed directly to Cloudflare Pages, GitHub Pages, or Vercel static hosting.
